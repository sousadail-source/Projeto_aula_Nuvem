Tecnologias & Conceitos

Estrutura utilizada neste projeto de implantação em nuvem pública.

Static Web Hosting

Serviço de alta performance para distribuição direta de ativos estáticos (HTML5, CSS3, JS) sem dependência de banco de dados.

Infraestrutura Nuvem

Disponibilidade global, baixo tempo de latência e custo simplificado através de hospedagem moderna em nuvem.

Continuous Deploy

Atualização automatizada do site a cada novo commit realizado no repositório do projeto via GitHub Pages.
